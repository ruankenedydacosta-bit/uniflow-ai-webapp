# Notificações

## Finalidade

Avisar o usuário sobre eventos dentro do aplicativo.

## Onde encontrar

Sino de notificações — na barra superior (desktop) ou no cabeçalho (mobile); também acessível pelo menu "Mais" no mobile.

## Passo a passo

1. Tocar no sino para abrir o painel de notificações.
2. Tocar em uma notificação para marcá-la como lida, ou usar "Marcar todas como lidas".

## Diferenças PF/PJ

Uma notificação pode ser global (aparece em qualquer espaço) ou vinculada a um espaço específico.

## Desktop / mobile

Mesmo conteúdo; o sino do desktop abre um painel em modal, o do mobile abre o mesmo painel adaptado à tela.

## Permissões

Cada usuário só vê as próprias notificações.

## Pré-requisitos

Nenhum.

## Limitações atuais

- **Somente notificações dentro do aplicativo — não há envio por e-mail nem por push.**
- **Não é possível excluir uma notificação.** Só é possível marcá-la como lida.
- Hoje, a única ação que realmente gera uma notificação automática é a conclusão do onboarding (mensagem de boas-vindas). Outros eventos (financeiro, metas, agenda, CRM) ainda não disparam notificações automaticamente, mesmo que o tipo já exista na estrutura de dados.

## Mensagens de erro conhecidas

Nenhuma específica documentada nesta fase.

## Funcionalidades ainda não disponíveis

- Notificações por e-mail ou push.
- Exclusão de notificações.
- Preferências de notificação configuráveis (a seção em Configurações está marcada "em breve").
- Disparo automático de notificações para eventos financeiros, de metas, agenda ou CRM.
