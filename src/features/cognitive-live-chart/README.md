# Cognitive Live Chart V1

Componente compartilhado de visualização cognitiva para Home e Financeiro mobile.

- `compact`: leitura curta na Home.
- `detailed`: exploração no Financeiro.
- `overview`, `uni-insight`, `comparison` e `forecast`: modos locais.
- SVG puro, CSS Modules e dados recebidos por props.
- Mocks locais são apenas fallback da V1.

Não há API, IA, voz, Supabase ou cálculo financeiro real nesta feature.
