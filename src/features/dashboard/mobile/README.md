# Home Mobile V1

Camada visual mobile da rota `/dashboard`. A composição representa um briefing
diário da Uni com dados estáticos e callbacks de navegação. Ela não consulta
serviços, não gera insights e não altera o dashboard desktop.

Ordem fixa: briefing, próximo passo, resumo financeiro, objetivos, insights e
atalhos. Os componentes recebem dados por propriedades para futura integração.
