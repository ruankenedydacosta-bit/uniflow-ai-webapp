# Structured Response Adapter

Consolida os snapshots do UNI OS em um único envelope profundamente imutável.
Não gera texto, voz, emoção, personalidade, prompt ou ação.

`communication` permanece inteiramente nula e `executionAllowed` permanece
sempre `false`.

`UNI_OS_ENABLED` continua desligada. Quando ativada explicitamente, a resposta
é criada somente em modo sombra e descartada.
