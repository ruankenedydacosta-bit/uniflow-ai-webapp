# Conversation Window Manager

Seleciona deterministicamente quais elementos do contexto compilado compoem a janela cognitiva futura do UNI OS.

- `SHORT`, `NORMAL`, `LONG` e `FULL` limitam apenas colecoes elegiveis.
- Mensagens preservam as mais recentes; colecoes ranqueadas preservam a ordem recebida.
- Reflection, Security e Permissions sao mantidos integralmente.
- O modulo nao resume, nao gera prompt, nao calcula tokens e nao altera snapshots.
- O modo sombra respeita `UNI_OS_ENABLED` e sempre descarta o resultado.
