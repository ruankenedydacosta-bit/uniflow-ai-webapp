# UNI OS Shadow Runtime

Encadeia Context, Memory, Planning, Reflection, Security, Permissions, Cognitive,
Structured Response e Communication na ordem obrigatória.

O runtime permanece inativo com `UNI_OS_ENABLED=false`. Quando ativado
explicitamente, executa apenas em modo sombra, valida invariantes e descarta o
resultado. Nenhuma ação, modelo, API, texto ou voz é acionado.

A telemetria contém somente duração, adapters executados, erros de validação e
contagem da execução sombra.
